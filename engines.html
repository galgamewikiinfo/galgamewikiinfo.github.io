PC 端核心攻略 · Locale Emulator

Windows PC 端转区、乱码与汉化补丁排错指南

解决“无法启动”、“文件路径错误”以及满屏问号方块字的最主流方案是使用 Locale Emulator（简称 LE）。

1

补齐系统必要运行库（防止报错无响应）

在运行任意转区工具或老游戏前，请确保电脑已安装 .NET Framework（建议 4.8 或更高版本）以及 Microsoft Visual C++ Redistributable（推荐安装微软常用运行库合集，避免缺失 msvcp*.dll）。

2

将 Locale Emulator 解压至纯英文路径

根据系统选择对应版本（Win10 推荐 v2.4.1.0，Win11 推荐 v2.5.0.1 及以上）。严禁在含中文的桌面或下载临时目录中直接解压安装，请放入类似 D:\Tools\LocaleEmulator\ 的全英文文件夹中。

3

以管理员身份运行 LEInstaller.exe 完成安装

右键点击 LEInstaller.exe 选择“以管理员身份运行”，在弹窗中点击 Install / Upgrade。安装过程中 Windows 资源管理器（桌面与任务栏）会短暂闪烁重启，属于正常向系统右键菜单注入模块的机制。

4

确保游戏路径全英文并右键转日区运行

这是 90% 报错的根源！整个路径（包括上层目录和游戏目录）不能出现中文或全角标点。例如应改为 D:\Games\Galgame\Senren\game.exe。随后右键游戏主程序 → Locale Emulator → Run in Japanese（若无法存档请选择 Run in Japanese (Admin)）。

5

正确处理汉化补丁与杀毒软件误报

  • 完全汉化硬盘版：大多数已移除日文区域检测，直接双击运行即可；误用 LE 反而可能导致字库调用异常。
  • 挂载型/外挂汉化补丁（如部分基于日文本体的补丁）：若打补丁后仍出现方块乱码或提示缺失 Shift-JIS 字符集，则仍需用 LE 转日区运行。
  • 杀毒误报：LE 及部分免 CD/汉化补丁 DLL 可能被 Windows Defender 隔离，请提前把工具与游戏文件夹加入排除项白名单。
  • 一键快捷方式：在程序上右键 → Locale Emulator → Modify this shortcut，即可生成双击直启动的转区快捷方式。
移动端攻略 · Android & iOS

手机端 KRKR (Kirikiroid2) 与 Artemis (Artroid+) 实战指南

按照正确流程解压并规范路径，手机躺平推 Gal 同样流畅稳定。

第 1 步：解压规范 重中之重

绝对不要使用网盘“在线解压”

网盘在线解压极易触发文件损坏或内容和谐，而手机自带文件管理器往往不能识别分卷包（如 .part1.rar）或高强度压缩算法。

  • 将所有压缩分卷完整下载至手机本地后，使用专业工具 ZArchiver 进行解压。
  • 解压后请新建全英文目录（如手机内部存储根目录下的 /Galgames/GameA/），切忌深层嵌套或留在 /Android/data/ 受限路径中。
第 2 步：KRKR 模拟器 .xp3 引擎

Kirikiroid2 常见白屏与闪退修复

  • 找不到文件/空白：进入手机“设置 → 应用管理 → Kirikiroid2 → 权限”，开启全部文件读写权限；检查目录名是否为纯英文。
  • 重命名主包：若目录中为“启动游戏.xp3”等中文命名，手动改名为 data.xp3 再点击启动。
  • 补丁与版本：部分移植需补齐 patch.tjs / xp3filter.tjs；官方原版停更于 1.3.9，高版本安卓闪退可换用适配新系统的社区修改版（如 1.4.x 魔改版）。
第 3 步：Artemis 模拟器 root.pfs 引擎

Artroid+ 路径禁忌与动态立绘兼容

  • 严禁任何非英文字符与空格：Artemis 模拟器对目录名极度敏感，路径出现中文、日文、韩文或空格往往直接闪退。
  • Emote 动态立绘报错：带有复杂动态立绘的作品若在旧版或 iOS 上报错，请升级至 Artroid+ 3.0 等较新版，或改用专门封装的直装版。
第 4 步：通用细节 字体与存档

文字乱码修复与存档防丢失技巧

  • 缺字/乱码：多为手机缺少指定字体所致。可将常见中文字体（如 simhei.ttf 或 wqy-zenhei.ttf）放入游戏根目录按提示重命名，或在模拟器设置中强行指定外部字体。
  • 存档防丢：确保手机剩余空间充足；务必使用游戏自带的保存界面（Save）手动存档，不要长期只依赖模拟器即时存档，以免跨版本更新时存档失效。
技术 FAQ · 故障排查

引擎与模拟器运行常见疑难解答

为什么同一台电脑有些游戏直接能打开，有些必须用 Locale Emulator？

Steam 官方中文版、Unity/Ren'Py 引擎作品以及去除了区域检测的完全汉化硬盘版通常采用 Unicode 编码，无需转区即可直接运行；而传统日文原版游戏（尤其使用 Shift-JIS 编码的老引擎）在简体中文 Windows 下直接启动会触发编码冲突，必须由 Locale Emulator 模拟日文系统区域环境才能正常读取。

用 Kirikiroid2 可以运行所有电脑上的 Galgame 吗？

绝对不可以。Kirikiroid2 仅支持 KRKR（吉里吉里）引擎且包含 .xp3 文件的作品（往往还需要手机端引导补丁）。如果文件夹里是 root.pfs，需要换用 Artroid+；如果是大量非通用 Windows .exe 独占引擎，则需要在电脑运行或通过 Winlator 等容器方案尝试。

游戏打开提示找不到存档目录或无法保存设置怎么办？

在 Windows 上请避免把游戏放在 C:\Program Files 等受系统 UAC 保护的目录，改放到 D:\Games\ 等非系统盘英文路径，并尝试用 LE 的“Run in Japanese (Admin)”启动；在手机端请确认已授予模拟器完整的存储权限且不要放在 /Android/data/ 内部。
